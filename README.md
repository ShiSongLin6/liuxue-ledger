# 留学记账看板 · Student Budget Dashboard

**留学生活每月花多少，现有的钱还能撑多久？**

给留学生的多币种记账看板：把日常生活费、学费住宿和资产变化分开看。无需注册，无需绑定银行，账目保存在当前设备的浏览器里。

**[打开在线版](https://shisonglin6.github.io/liuxue-ledger/) → 先看示例（虚构数据）**

> **English overview:** A single-file budget dashboard for international students. Track multi-currency spending, separate tuition and accommodation from living costs, and estimate how long your savings could last at your recorded spending rate. No signup or bank connection. **The interface is currently in Chinese.** Data stays in this browser; export a JSON backup regularly. There is no automatic cross-device sync.

适合：想手动整理留学开销、区分家里代付和自己账户余额的人。金额与汇率需要自行填写；“还能撑多久”是基于已记数据的估算。

---

## 怎么用

1. 打开上面的链接，点「先看示例」看看效果（虚构数据）。
2. 点「退出示例，开始记我的账」，在「设置与备份」里填好本币、外币、汇率，以及到达当地的日期和不打算花掉的保底金额。
3. 平时在「记账」里一笔笔记；每月末在「资产快照」里记一次所有账户加起来的总资产。
4. **定期导出备份。** 数据只存在你这台设备的浏览器里，超过 14 天没备份，看板顶部会提醒你。

手机上可以用浏览器的「添加到主屏幕」，像 App 一样打开。

## 它能回答的问题

- **我正常一个月要花多少？** 每月生活花销 = 日常（含家庭代付）+ 会员订阅 + 偶发大额。学费、住宿单独放在「学业刚性」，不会把月花销撑爆。
- **这个月是不是花多了？** 拿日常开销和前几个月的中位数比，超过 30% 会标黄。
- **大钱都花在哪了？** 大额收支按月份分组，再分成上万、千元级、百元级三档；学业支出和过路款单独列，不混进入 / 出合计。
- **钱还能撑几个月？** （当前总资产 − 保底金额）÷ 到达当地以来的月均生活花销。
- **我是不是漏记了？** 每月末记一次总资产，看板用余额倒推实际花了多少，再和你记下的对比。状态列：✅ 对上了，🔴 有漏记，⚠️ 记的比余额减少的多（可能漏记了收入，或快照漏了账户）。

## 隐私

所有数据只保存在你这台设备的浏览器里（localStorage），**不会上传到任何服务器**，网站作者也看不到。
所以换手机、换浏览器、清理缓存都会让数据消失，也不会在不同设备之间同步。请到「设置与备份」里导出备份（JSON），需要时再导入。

## 记账口径

| 性质 | 含义 | 算不算 |
|---|---|---|
| 收入 | 家里生活费、奖学金、工资 | 算真实收入 |
| 支出 | 自己花的钱 | 算支出 |
| 家庭代付 | 家里直接替你付（亲情卡、父母交学费） | 算你的消费，不算你账户的钱 |
| 过路款 | 别人转来、你再转走 | 都不算 |
| 资产转移 | 换汇、账户互转、还信用卡 | 都不算 |

外币金额写成「−£26.86 / ≈9.3000 / ¥250」：原币 / 汇率 / 折本币，实际付款的货币标颜色。
填了「实付本币」（银行实际扣了多少）就按实付算、汇率是真实的；没填就按设置里的汇率估算，汇率前面加 ≈。

## 导入

可以下载 CSV 模板，用 Excel 填好后另存为 CSV（UTF-8）再导入。
列：`日期,项目,金额,币种,实付本币,性质,类别,账户,备注`

## 离线使用 / 下载

在 [Releases](https://github.com/ShiSongLin6/liuxue-ledger/releases) 里下载最新版本的 zip，解压后双击 `index.html` 就能用，不需要联网。
注意：本地文件版和在线版在浏览器看来是两个不同的网站，数据不互通，需要用「导出备份 / 导入备份」搬过去。

## 技术

只有一个 `index.html`，没有依赖，没有统计代码。想自己部署的话，fork 后开启 GitHub Pages 就行。
