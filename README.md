# 留学记账看板

给留学生用的记账看板，打开网页就能用，不用注册。

**在线使用：** https://shisonglin6.github.io/liuxue-ledger/

## 它能回答的问题

- **我正常一个月要花多少？** 每月生活花销 = 日常 + 固定月费 + 偶发大额。学费、住宿单独计算，不会把月花销撑爆。
- **这个月是不是花多了？** 拿日常开销和前几个月的中位数比，超过 30% 会标黄。
- **大钱都花在哪了？** 大额收支按月份分组，再分成上万、千元级、百元级三档。
- **按现在的速度，钱还能撑几个月？**
- **我是不是漏记了？** 每月末记一次总资产，看板用余额倒推实际花了多少，再和你记下的对比，算出漏记率。

## 隐私

所有数据只保存在你这台设备的浏览器里（localStorage），**不会上传到任何服务器**，网站作者也看不到。
换电脑或清理浏览器前，请到「设置与备份」里导出备份。

## 记账口径

| 性质 | 含义 | 算不算 |
|---|---|---|
| 收入 | 家里生活费、奖学金、工资 | 算真实收入 |
| 支出 | 自己花的钱 | 算支出 |
| 家庭代付 | 家里直接替你付（亲情卡、父母交学费） | 算你的消费，不算你账户的钱 |
| 过路款 | 别人转来、你再转走 | 都不算 |
| 资产转移 | 换汇、账户互转、还信用卡 | 都不算 |

外币支出如果填了「实付本币」（银行实际扣了多少），就按实付算，否则按设置里的汇率折算。

## 导入

可以下载 CSV 模板，用 Excel 填好后另存为 CSV（UTF-8）再导入。
列：`日期,项目,金额,币种,实付本币,性质,类别,账户,备注`

## 技术

只有一个 `index.html`，没有依赖，没有统计代码。想自己部署的话，fork 后开启 GitHub Pages 就行。
